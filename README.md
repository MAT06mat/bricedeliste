# Brice de liste

Site de la liste des cdp `Brice de Liste` de l'INSA Lyon

## Installation

Installation des dépendances

```bash
npm i
```

Dans un `.env.local` à la racine :

```.env
VITE_API_URL="http://localhost:8080/"
```

## Dévellopement en local

Lancement du site :

```bash
npm run dev
```
